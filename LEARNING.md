Q1 - why you have installed all these things in your project
Ans: I used these specific packages to build a responsive and user-friendly application. I implemented React Router DOM for seamless page navigation and Axios to efficiently handle API requests. For the UI, I used Lucide React for clean icons and React Hot Toast to give users instant, elegant notification pop-ups. Finally, I integrated React Dropbox to handle file management and storage directly within the application
